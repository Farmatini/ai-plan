# Правила работы над AI Plan

Объяснения для владельца — на русском. Перед изменениями прочитать README.md, ARCHITECTURE.md и [Инструкцию AI агенту](AI_AGENT_INSTRUCTIONS.md).

1. Назначение инструмента — показывать человеку устройство программы на любом языке. Не добавлять встроенную AI модель, облачные сервисы или автоматический анализ исходников без отдельной задачи.
2. Источник схемы — `project.canvas`. `initial-data.js` генерируется командой `node sync-example.cjs`. Не редактировать его отдельно.
3. Внутренние связи идут между сущностями одной системы, межсистемные — между группами. Цвета типов должны соответствовать отдельной легенде на холсте.
4. Сохранять ID, содержательные пользовательские правки, точные имена и относительные пути. Реализацию проверять по исходникам; планы явно помечать.
5. При изменении редактора обновлять его схему и ARCHITECTURE.md, если изменились обязанности или связи. Учебная схема намеренно показывает основные сущности; не выдавать её за полный граф всех функций.
6. Сохранять запуск через file://, без сборки и сети; отдельный ключ черновика из config.js. Увеличение названий групп ограничено уровнем 23%.
7. После изменений запускать `node verify.cjs`; при изменении поведения — подходящие браузерные проверки по TESTING.md. В CHANGELOG.md записывать только реально проведённые проверки.
8. Не публиковать репозиторий, не создавать теги и релизы без соответствующей задачи пользователя. Готовность файлов к GitHub сама по себе не означает публикацию.
