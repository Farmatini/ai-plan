# Как устроен AI Plan

Редактор написан на HTML, CSS и обычном JavaScript. Работает на стороне браузера, без фреймворка и сетевого сервиса. `project.canvas` — небольшой учебный пример его собственной архитектуры.

Схема показывает файлы и выбранные основные функции. Это **не полный граф всех функций**. Цветовая легенда и обе детализации связей уже применены: внутренние стрелки соединяют сущности одной группы, межсистемные соединяют рамки групп.

## Файлы

| Файл | Назначение |
|---|---|
| [index.html](index.html) | Элементы интерфейса, панели свойств, контейнеры карточек и SVG связей. Подключает скрипты через defer. |
| [style.css](style.css) | Оформление, карточки, группы, порты, линии и адаптация панелей. |
| [config.js](config.js) | Название, отдельный ключ черновика, путь схемы и сообщения этой копии. |
| [canvas-core.js](canvas-core.js) | Проверка и копирование данных, цвета, границы, геометрия портов и линий. Экспортирует CanvasCore в браузер и module.exports для проверок Node.js. |
| [app.js](app.js) | Состояние редактора, отрисовка, ввод, выделение, группировка, свойства, история, импорт и выгрузка. |
| [project.canvas](project.canvas) | Канонический файл учебной схемы. Для своего проекта его можно заменить своей картой. |

## Путь действия пользователя

Например, создание стрелки: пользователь нажимает два порта → `connect(id, side)` добавляет запись в `data.edges` → `changed()` сохраняет черновик и вызывает `render()` → `anchor()` определяет точки, `curve()` вычисляет SVG путь → `inspector()` позволяет подписать связь.

Пример переноса группы: `startNode(e, n)` собирает выбранные узлы и содержимое группы через `moveIds()` → обработчик pointermove меняет координаты → `endGesture()` сохраняет черновик. Принадлежность группе определяется полным геометрическим включением, без скрытой таблицы родителей.

При выгрузке `download()` проверяет модель через `validate()`, создаёт JSON Blob и инициирует скачивание. При импорте файл сначала разбирается и проверяется; повреждённый файл не заменяет текущую карту.

## Состояние

`data.nodes` и `data.edges` содержат схему. Выделение, незавершённая связь, текущий жест и положение камеры живут отдельно в app.js. История undo/redo хранит снимки схемы. Браузерный черновик записывается в localStorage; имя ключа задаёт config.js.

Узлы имеют стабильный ID и геометрию. Цвет хранится в `color`; его значение поясняется легендой. Первая строка текстового узла становится заголовком, остальные — описанием. Текст вставляется через textContent.

## Как инструмент сформировался

1. Сначала понадобился один простой холст: блоки с русским описанием, изменение размеров, линии с разных сторон, выделение и группы.
2. Затем появились крупные подписи групп при отдалении и настройка фона групп.
3. После проверки обзора увеличение подписей ограничили уровнем 23%, а выбор цвета распространили на обычные блоки.
4. Следующий шаг — универсальная самостоятельная копия, инструкция AI агенту, легенда типов и разделение внутренних и межсистемных связей.

Это пример последовательной разработки по обратной связи человека: небольшая возможность → проверка → уточнение поведения. На карте можно проследить, какие файлы обеспечивают каждую из этих возможностей.
