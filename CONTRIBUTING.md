# Разработка

Обычное использование не требует установки. Для служебных скриптов нужен Node.js.

1. Прочитайте README.md, AGENTS.md и AI_AGENT_INSTRUCTIONS.md.
2. Измените нужные исходники. Сохраняйте работу без сети через file://.
3. Если изменились обязанности или связи, исправьте project.canvas и ARCHITECTURE.md.
4. Запустите `node sync-example.cjs`, затем `node verify.cjs`.
5. При изменении поведения проверьте его в браузере по TESTING.md. Опишите выполненные проверки в CHANGELOG.md.

Настройки конкретной копии находятся в config.js. При переносе в другой проект задайте уникальный storageKey, название и canvasPath. projectRoot используется проверкой ссылок документации. downloadName — имя выгружаемого файла; projectFileLabel — подсказка человеку.

Исходники редактора намеренно простые: обычные локальные файлы, без шага сборки. Не добавляйте зависимость ради возможности, уже доступной в браузере. Новые форматы импорта, автоматическую обработку репозитория и изменение правил сохранения обсуждайте отдельной задачей.

В описание изменения включайте конкретное поведение до/после и результат проверок. Не записывайте в схему функции, которые только предлагается реализовать, со статусом «РЕАЛИЗОВАНО».
