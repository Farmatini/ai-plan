# Проверки

Использование редактора не требует Node.js и Playwright. Они нужны только для проверки изменений.

Из папки AI Plan:

```sh
node sync-example.cjs
node verify.cjs
```

Первая команда обновляет стартовый пример. Вторая проверяет модель, цвета, геометрию, повреждённый импорт, совпадение примера, относительные ссылки и два уровня связей эталонной схемы.

Для браузерного теста требуется пакет Playwright и установленный Edge/Chrome либо браузер Chromium Playwright:

```sh
node smoke-test.cjs
```

Если пакет установлен в другом месте, передайте каталог node_modules:

```sh
node smoke-test.cjs "<каталог node_modules с playwright>"
```

Тест запускает отдельный headless-профиль, не использует пользовательские вкладки. Проверяет создание/перенос/размер блоков, перенос группы, цвета и сброс, связи, выгрузку/импорт, ошибочный импорт без потери текущей схемы, историю и черновик после перезагрузки. Предел увеличения подписей проверяется на 23%, 12% и 8%. Результаты и скриншоты записываются в игнорируемый test-output/.

Дата подготовки: 2026-10-29. Фактически проведённые проверки перечисляются в CHANGELOG.md. Ручная проверка в другом браузере полезна при изменении поведения браузерных API.
